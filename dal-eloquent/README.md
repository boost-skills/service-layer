# Data Access Layer Skill: Eloquent-first

This skill teaches AI agents to write pragmatic Laravel DAL code with Eloquent as default, while preserving SOLID discipline and reliability.

## File map

- `SKILL.md` - decision rules and execution workflow.
- `principles.md` - Eloquent-first architecture boundaries.
- `transactions-and-consistency.md` - transaction and side-effect guarantees.
- `testing-matrix.md` - required tests for models/scopes/query services.
- `anti-patterns.md` - over-abstraction and performance smells.
- `examples.md` - practical Eloquent and service templates.
- `modern-enhancements.md` - modern upgrades and migration triggers.

## How to use

1. Start with `SKILL.md`.
2. Implement with Eloquent as default path.
3. Extract abstraction only where complexity is proven.
4. Guard performance and consistency with tests.

## Scope

Backend Laravel persistence for products that prioritize delivery speed and maintainable complexity.

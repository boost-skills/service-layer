# Data Access Layer Skill: Repository + Query + DTO

This skill guides AI agents to implement a robust Laravel DAL with explicit write repositories, dedicated read query objects, and typed contracts.

## File map

- `SKILL.md` - compact entrypoint and decision rules.
- `principles.md` - architecture boundaries and SOLID rules.
- `transactions-and-consistency.md` - transaction, outbox, and idempotency policy.
- `testing-matrix.md` - mandatory test coverage by DAL artifact type.
- `anti-patterns.md` - patterns to reject during coding/review.
- `examples.md` - templates for repository/query/DTO wiring.
- `modern-enhancements.md` - modern upgrades and migration triggers.

## How to use

1. Start with `SKILL.md`.
2. Pick the specific guide file based on the current task.
3. Implement DAL contracts first, then concrete adapters.
4. Validate with integration tests and performance checks.

## Scope

Focused on backend Laravel persistence architecture for medium and high complexity domains.
